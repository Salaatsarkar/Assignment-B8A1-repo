# Assignment B8A1 Overview

This assignment gave me an opportunity to practice TypeScript. I completed eight problems, and each one helped me improve my coding and problem-solving skills.

I worked with functions, optional parameters, union types, tuples, arrays, generics, interfaces, classes, inheritance, access modifiers, Promises, and async/await.

## My Assignment Problem-Solving Experience

**Problem 1: Multiplication Using Optional Parameters**
I created a function that takes a number and an optional multiplier. I used conditions to check the multiplier and return the correct result.

**Problem 2: Input Processing with Union Types**
I used a union type to accept string, number, and boolean values. I applied `typeof` for type narrowing and `never` for exhaustive checking.

**Problem 3: Coordinate Formatting with Readonly Tuple**
I created a readonly tuple for latitude, longitude, and location name. I used destructuring to get the values and format them into a string.

**Problem 4: Array Concatenation Using Generics**
I created a generic function with rest parameters and used `concat()` to combine arrays of the same type.

**Problem 5: Filtering Courses with Interfaces**
I used a `Course` interface and conditions to find published courses that meet the minimum student requirement without changing the original array.

**Problem 6: Extracting Object Properties with Generics**
I used `keyof` and indexed access types to get values from valid object properties while maintaining type safety.

**Problem 7: Object-Oriented Programming with Inheritance**
I created `Employee` and `Manager` classes. I practiced inheritance, constructors, `super()`, access modifiers, and getters.

**Problem 8: Asynchronous Age Validation with Promises**
I used `Promise<string>`, `resolve`, `reject`, and `setTimeout()` to check age and handle approval or rejection.

Conclusion :This assignment helped me understand TypeScript concepts. It improved my confidence and problem-solving skills.
